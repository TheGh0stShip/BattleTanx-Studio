# Studio feature matrix

Generated by `tools/runtime_feature_matrix.py`; do not edit by hand.

"Studio" means Studio can author, validate, save and package the feature. "Runtime" is what a PC runtime declares in its `btga-runtime.json` capabilities file. No runtime has declared capabilities yet, so every feature is **pending** in the runtime column: nothing here may be described as playable until a runtime declares it.
